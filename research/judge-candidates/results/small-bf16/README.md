# Published synthetic benchmark evidence

Snapshot of the completed six-condition BF16 experiment. Runtime logs, bearer keys, model weights and adapters are excluded. Absolute workspace paths in metadata are normalized to `${REPO_ROOT}`. Original completion hashes refer to the original local files; normalized public JSON and edited report have different hashes. JSONL rows contain synthetic case identifiers, labels, probabilities and timing metadata, not customer documents.

The scripts write fresh runs under ignored `evidence/judge/small-comparison-bf16/`. These checked-in files are the historical result snapshot, not a new run.
